# Common Ground design direction

A quiet, compact product workspace with a graphite navigation rail, cool neutral surfaces, restrained blue actions, and typography that keeps tasks and conversation readable. The installed Awesome DESIGN.md Linear reference informed the fine borders, small radii, spacing rhythm, and focused product interface. This project uses original branding and system fonts.

The task is the primary object. Four columns remain horizontally scrollable on narrow screens; an accessible editor offers the same status change as dragging. Team conversation stays alongside the board on large screens and moves into a drawer on smaller screens. Counts, progress, people, chat, files, and activity all come from the server. Demo tasks and accounts are explicitly identified.

Themes use the same information hierarchy. Focus rings, native form labels, a skip link, live status announcements, reduced-motion handling, and modal dialogs are part of the interface. No external image or font service is required.

Browser verification covered registration through an invitation, two simultaneously connected users, live chat, task creation, pointer dragging, search, file upload, and responsive themes. Backend tests use a separate temporary database.
